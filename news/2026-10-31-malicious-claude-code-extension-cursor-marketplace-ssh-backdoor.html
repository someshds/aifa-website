Trojanised AI coding extension reached 5,000 users — a supply chain warning for all businesses

A malicious copy of a Claude Code extension was uploaded to Cursor's marketplace, carrying an SSH backdoor that survived uninstallation. Around 5,000 users installed it before it was removed after 11 hours. No extension marketplace is immune.

31 OctPublished 2026
4 minDaily brief
Impact 8/10Security signal

A trojanised version of a Claude Code extension appeared on Cursor's extension marketplace — one of the most popular AI coding tool stores — and was installed by approximately 5,000 users before it was taken down 11 hours after upload.

🔊Listen to this article

What happened

The extension was a near-identical copy of a legitimate Claude Code integration for the Cursor IDE. The malicious version added a hidden SSH backdoor — a remote access implant that gave the attacker a persistent connection to any machine that installed it.

BleepingComputer and The Register confirmed that the backdoor persisted after the extension was uninstalled. This is the most dangerous characteristic of the attack: removing the extension through the normal marketplace interface did not remove the implant. Affected users needed to identify and manually remove the backdoor process.

Cursor removed the extension after approximately 11 hours. An estimated 5,000 users had installed it during that window.

Why this matters beyond AI coding tools

For most UK small business owners, the immediate risk is low: Cursor is primarily used by software developers, and the backdoored extension targeted developer machines specifically. But the wider pattern is directly relevant to any business using AI tools.

Extension and plugin marketplaces for AI tools — VS Code, Cursor, browser extensions for ChatGPT, add-ons for Google Workspace — operate on a "publish and review" model where malicious uploads can circulate for hours or days before detection. Most small businesses install these tools without verifying publisher identity, download counts, or reviews.

This incident follows the OpenCode Console breach reported in October, in which AI provider API keys were exposed through a compromised developer tool. The pattern is consistent: AI tool supply chains are an active attack surface.

Coverage context

The incident was reported on 31 October 2026 by BleepingComputer, Help Net Security, and The Register. The 5,000 user estimate and 11-hour window are from BleepingComputer's reporting. Cursor confirmed the removal but had not published a post-incident report at time of writing.

Operator actions — three things to do now

  • Audit AI extensions installed on your team's machines — browser extensions and IDE plugins for AI tools (ChatGPT, Claude, Copilot) can have broad system permissions. Review what is installed, verify the publisher is the official one, and remove anything unused or unverifiable.
  • Treat extension marketplace installs like software installs — the same caution that applies to downloading unknown software applies to browser and editor extensions. Check the publisher name matches the AI company exactly, not a near-copy.
  • If you use Cursor with a Claude integration, verify your installation — confirm the extension version and publisher against the official source before continuing to use it. If you installed any Claude Code extension from Cursor's marketplace in late October, run a full malware scan.
